# briefing-script

起草汇报稿：按鱼骨结构（背景 → 现状 → 转折 → 原因 → 结论 → 行动）把数据分析或项目结论写成简洁的口头汇报稿。

## 安装

```bash
git clone https://github.com/imQiwei/briefing-script.git ~/.claude/skills/briefing-script
```

Claude Code 会按 `SKILL.md` 里的 `description` 自动匹配触发，也可以用 `/briefing-script` 手动调用。完整说明见 [SKILL.md](SKILL.md)。

skill 用中文编写。示例数字均为虚构，表名、字段名为通用占位，请按自己的数据平台替换。

更多 skills：[imQiwei/claude-skills](https://github.com/imQiwei/claude-skills)
